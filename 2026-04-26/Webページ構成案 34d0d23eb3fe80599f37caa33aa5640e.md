## 2. 企画の位置づけ

### 逆オープンキャンパス：学科が街へ出る

これまでの高校生向け広報は、大学に「来てもらう」形式が中心だった。  本企画は逆に**学科が意図を持って街に出る**。元町映画館とこうべまちづくり会館という神戸・元町の固有の場所を会場に、学科の制作物・思考・人が街と接触する2日間を設計する。オープンキャンパスの参加者がキャンパスという文脈の中で学科を見るのとは異なり、街という日常の延長で学科と出会うことができる。高校生にとって参加の敷居が下がると同時に、**学科が社会に向けて開く姿勢そのものを体現する場**になる。

### 2027年度新カリキュラムとの接続

単なる作品発表の場ではなく、**2027年度に始動する新カリキュラムの理念を、実際の社会の場で先行して紹介する試み**として設計している。新カリキュラムが打ち出す方向性——社会の問いとデザイン・メディア表現の接続、コミュニケーションの形成——をイベント全体の構造に埋め込む。

## 3. 学外イベントのコンセプトと新カリキュラムの方向性

### 新カリキュラムが示す回路

新カリキュラムの核心は**デザイン思考による課題解決ではなく、問いと実装の接続・中間レイヤー**にある（社会課題解決のような実学的観点自体は学科の方向性に必ずしもそぐわない）。 社会のさまざまなレイヤーに存在する問い（？）に対して、デザインとメディア表現学の知見および実践がアンテナを張り、応答し、対話を生み出す。その回路を教育として具体化することが新カリキュラムの要点である。

![TouchDesigner Workflow-2026-04-25-172437.png](Web%E3%83%9A%E3%83%BC%E3%82%B8%E6%A7%8B%E6%88%90%E6%A1%88/TouchDesigner_Workflow-2026-04-25-172437.png)

**デザインが問いと表現をつなぐ翻訳レイヤーになる**

- この回路は一方向の「発信」ではなく、社会との往復運動として機能する

### デザイン思考は新カリキュラムの回路の一部として機能する

デザイン思考は「問いを解く」ことを目的とするが、この回路が目指すのはそれとは異なる——問いを表現に変換し、**社会との対話の回路を開くこと**。答えを出すことではなく、往復運動を持続させることが目的である。したがって「デザイン思考による課題解決」という言い方は回路全体の説明としては正確ではなく、デザインレイヤーの記述にとどめる。

### 新カリキュラムの変更点：主に2つ

**軸A：デザイン × 社会**

- 情報デザインおよびデザイン思考的アプローチの強化
- 社会の問いを構造化・可視化する能力の育成
- 地域・他者・異分野との連携

**軸B：デジタル × クリエーション**

- デジタル表現特にAI関連分野に関する新科目の開設
- メディア表現の現在形を扱う

### イベントへの落とし込み

3つのプログラムは、上記の回路の異なる局面を体現する。

| プログラム | 回路との対応 |
| --- | --- |
| **展示** | 表現の結果を社会に開く。問いへの応答を可視化する |
| **上映** | 映像表現が、見る人に問いを投げかける |
| **イベント** | 参加者自身が問いを立て、デザインで構造化し、表現に変換するプロセスを体験する |
- ワークショップの設計そのものが、新カリキュラムの教育プロセスの実演になることを目指す

## 4. Webサイトの設計方針

### 基本方針

- 新カリキュラムという言葉は**サイト上では使わない**
- ただし新カリキュラムに関わる「問い→デザイン→表現→対話」の回路はサイトおよびコンテンツの構造に**埋め込む**
- 高校生・保護者・教員のどの読者にも機能するよう、3層の読み深度を設計する

```
表層（高校生・Z世代）    かっこいい・楽しそう・現在の自分／将来像に関係がある
中層（保護者・教員）  学科／カリキュラムがちゃんとしている・時代に合っている
深層（学科の文脈）   新カリキュラムの理念を体現する最初の公開の場
```

### ページ構成（確定）

```
HERO        タイトル・会期・キャッチコピー
NEWS        更新情報・Instagram連携（@mediastudies_kwu）
PROGRAM 	 上映 / 展示 / イベント（3パネル）
ABOUT		    開催概要
ACCESS      会場マップ（Google Maps）
FOOTER      学科サイトへのリンク
```

- サイトはイベント情報のみ記載
- 学科サイトへの動線はFOOTERに設置

### データ管理

- Excelで管理（meta / news / screening / exhibition / events の5シート）
- CSVで書き出し → JSONに変換してWebサイトに反映
- ワークショップ申込はMicrosoft FormsへのリンクをExcelで管理（必要なイベントごとにイベント担当者が咲く英）
