まちなかキャンパス 2026 — デザインテーマ

静的サイト（MEDIA x MOTOMACHI）の参照用まとめ。このファイル単体で表示できます（スタイルはすべて下記 <style> 内。外部 CSS への link なし）。テクスチャ背景・ヒーロー写真・地図などの装飾は除き、色・タイポ・プログラム別アクセント・コンポーネント規則を記載。本番実装の単一ソースは css/tokens.css。

フォントは @import で Google Fonts を読み込み（要ネット接続）。オフライン時はシステムフォントにフォールバックします。

生成日: 2026年（リポジトリ現行版）

コンセプト

フライヤー連動の「街へひらく学び」。甲南女子大学公式色（紺・赤・ワインレッド）をイベントのアクセントに取り込み、パネル地は大学サイトと同系のライトグレー（#F2F2F2）＋白カード。プログラム種別は黒／紺／赤／紫（上映）、担当分野の案Bのみライム緑を補助色に。見出しは明朝＋英字モノスペースの対比。

  • 英字ロゴ・ラベル: DM Mono（大文字・レタースペース広め）
  • 和文見出し・タイトル: Shippori Mincho B1（800）
  • 本文・UI: Noto Sans JP（400 / 500 / 700）

担当分野（3分野）カラーリング案

2027年度カリキュラム刷新の3分野（ヴィジュアルカルチャー・クリエイション／AI・ソーシャルデザイン）向けの参照用配色。 本番サイトの .ev-domain（担当分野チップ）は現状中立グレーのまま。フライヤー・学科案内・スライド等の別制作物では、以下の案A／案Bを使い分け可能。

案Aは大学パレット3色にマッピング（赤＝VC、紺＝クリエイション／AI、ワインレッド＝ソーシャルデザイン）。上映・映画館は従来の紫（--brand-purple）のまま。 案Bはプログラム種別（紺／赤／ワインレッド）と被らないよう、ライム緑・明るい紺・深いワインレッドで分野専用色を定義。
