# スタイルガイド（まちなかキャンパス 2026）

実装の単一のソースは [`css/tokens.css`](../css/tokens.css) の `:root` 変数です。ここではトークンの意味と更新時の指針をまとめます。

## サーフェス・テキスト

| トークン | 値（現在） | 用途 |
|----------|------------|------|
| `--bg-main` | `#0f1115` | ヒーロー背景などダーク面 |
| **`--bg-light`** | **`#f7f0e6`** | **プログラム／開催概要／アクセス**の `.container` パネル背景（`background: var(--bg-light)`）。クリーム色で白カード（`#fff`）と区別 |
| `--brand-surface` | `#f7f0e6` | `body` の下地色（ページ全体のベース）。`--bg-light` と揃える |
| `--bg-light-rgb` | `247, 240, 230` | `rgba(var(--bg-light-rgb), α)` でタイムライン帯・イベント時刻列などの半透明トーンに利用 |
| `--text-dark` | `#0d0d0d` | 本文・見出しの基準色（フライヤー「黒」に準拠） |
| `--text-light` | `#fff` | ダーク背景上のテキスト |
| `--rule` | `rgba(13,13,13,0.12)` | 区切り線 |
| `--dim` | `rgba(13,13,13,0.45)` | 補助テキスト |

パネル色を変えるときは **`--bg-light` と `--brand-surface` を同じ値に保ち、`--bg-light-rgb` をその HEX に対応する RGB に合わせる**こと。

## ブランドカラー（フライヤー連動）

| トークン | HEX | 用途の目安 |
|----------|-----|------------|
| `--brand-black` | `#0d0d0d` | 展示のアクセント |
| `--brand-blue` | `#1261a6` | トーク／講義（lecture）、フォーカスリング寄り |
| `--brand-magenta` | `#d94e81` | ワークショップ、リンクアクセント（`--accent`） |
| `--brand-purple` | `#4c4784` | 上映・元町映画館まわり |
| `--brand-*-rgb` | 同上の RGB 三元組 | `rgba(var(--brand-*-rgb), α)` |

互換用：`--accent`（マゼンタ）、`--accent-2`（青）、`--accent-3`（紫）。

## その他

- **地図ピン**：`--venue-pin-a`（まちづくり会館＝青）、`--venue-pin-b`（元町映画館＝紫）
- **タイポグラフィ**：本文 Noto Sans JP、見出き明朝／DM Mono は HTML と `css/` 以下のクラスに準拠

パネル底色は **クリーム `#f7f0e6`**（フライヤーのオフホワイト `#f2eae4` に近いが、パネル上でやや明るめに調整）。
